01

Control de flujo y manejo de errores

Permiten decidir qué código se ejecuta según una condición y reaccionar de forma controlada cuando algo sale mal.

if...else

Clasificador de notas

Evalúa condiciones en orden; se ejecuta el primer bloque cuya condición sea verdadera.

function classifyGrade(grade) {
  if (grade >= 90) {
    return 'Aprobado con excelencia';
  } else if (grade >= 70) {
    return 'Aprobado';
  } else if (grade >= 60) {
    return 'Ampliación';
  } else {
    return 'Reprobado';
  }
}

switch

Plan según el día

Compara un valor contra varios case. Si se omite break, la ejecución continúa al siguiente caso.

switch (day) {
  case 'sabado':
  case 'domingo':
    message = 'Fin de semana';
    break;
  case 'viernes':
    message = '¡Casi fin de semana!';
    break;
  default:
    message = 'Día laboral';
}

try / catch / throw

Validador de edad

throw lanza un error, catch lo captura y finally se ejecuta siempre. Pruebe con texto, decimales o valores negativos.

try {
  const age = validateAge(input.value);
  // solo llega aquí si no hubo error
} catch (error) {
  console.error(error.name, error.message);
} finally {
  // se ejecuta siempre
}

function validateAge(value) {
  if (value === '') throw new Error('Campo vacío');
  if (isNaN(value)) throw new TypeError('No es número');
  if (value < 0 || value > 120)
    throw new RangeError('Fuera de rango');
  return Number(value);
}

Objetos Error

Tipos de error

Todo error es un objeto con name y message. Además de los nativos, se pueden crear errores propios extendiendo Error.

class ValidationError extends Error {
  constructor(field, message) {
    super(message);
    this.name = 'ValidationError';
    this.field = field;
  }
}
// Nativos: TypeError, RangeError,
// ReferenceError, SyntaxError...

03

Funciones

Bloques de código reutilizables que reciben parámetros y pueden devolver un valor.

Definir funciones

Formas de declarar

Declaración, expresión, función flecha, parámetros por defecto y parámetros rest.

// Declaración
function greet(name) { return `Hola, ${name}`; }

// Expresión
const greetExp = function (name) { ... };

// Función flecha
const greetArrow = (name) => `¡Pura vida, ${name}!`;

// Parámetro por defecto
function welcome(name = 'invitado') { ... }

// Parámetros rest
function sumAll(...numbers) {
  return numbers.reduce((t, n) => t + n, 0);
}

Llamar funciones

Calculadora con callbacks

Una función se llama con nombre(argumentos). También se puede pasar como argumento a otra función (callback).

const operations = { add, subtract, multiply, divide };

function calculate(a, b, operation) {
  return operation(a, b); // se llama al callback
}

calculate(8, 2, operations.divide); // 4

Llamar funciones

Factorial recursivo

Una función recursiva se llama a sí misma hasta alcanzar un caso base.

function factorial(n) {
  if (n <= 1) return 1;          // caso base
  return n * factorial(n - 1);   // llamada recursiva
}

04

Expresiones y operadores

Los operadores combinan valores para producir un resultado: asignar, comparar, calcular y razonar con lógica.

Asignación

Modificar una variable

Los operadores compuestos combinan una operación con la asignación.

let x = 10;
x += 5;   // x = x + 5
x -= 3;   // x = x - 3
x *= 2;   // x = x * 2
x /= 4;   // x = x / 4
x %= 3;   // x = x % 3
x **= 2;  // x = x ** 2
x = 10
Comparación

== frente a ===

El valor A se toma como número y el valor B como texto para evidenciar la diferencia entre igualdad flexible y estricta.

5 == '5'    // true  (convierte el tipo)
5 === '5'   // false (compara valor y tipo)
5 != '5'    // false
5 !== '5'   // true
5 > 3       // true

07

Colecciones indexadas

Estructuras ordenadas por índice (empezando en 0): arreglos comunes y arreglos tipados para datos binarios.

Arreglos

Lista de compras

Métodos que agregan o quitan elementos al inicio o al final, ordenan e invierten.

const list = ['Arroz', 'Frijoles', 'Café'];
list.push('Leche');     // agrega al final
list.unshift('Pan');    // agrega al inicio
list.pop();             // quita el último
list.shift();           // quita el primero
list.sort();            // ordena
list.reverse();         // invierte
Arreglos

Métodos de transformación

Recorren el arreglo y devuelven un resultado sin modificar el original.

const nums = [12, 5, 8, 21, 3];
nums.map(n => n * 2);
nums.filter(n => n % 2 === 0);
nums.reduce((total, n) => total + n, 0);
nums.find(n => n > 10);
nums.some(n => n > 20);
[...nums].sort((a, b) => a - b);
